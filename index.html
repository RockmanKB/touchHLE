Double Dragon Controls

Bind your keyboard keys and controller buttons to the game's on-screen pad, for one or two players. When you're done, download the launcher. It starts the patched touchHLE with your bindings, and for two players it opens two linked windows.

Menus and other screens

These follow from your bindings automatically. touchHLE watches which screen the game is on and changes what your buttons do.

ScreenWhat your controls do
Quitting to the menuIncludes a fix for the original game's freeze on "Now Loading" after quitting a stage.
Game speedFaster speeds make everything move and react sooner, like a turbo mode; the fight clock counts down faster too. Music and sound effects are not sped up. Both co-op windows always use the same speed.
Classic combosWhen ticked (top of the page), the game's own move rules change for both players: Left/Right + D does the headbutt and Jump + Punch (Auto mode: Jump + Attack) pressed together does the back elbow, like the older games. Up + D and Down + D become a plain D. Nothing is delayed or faked, so punches and jumps react exactly as normal.
FightingEverything works as bound above. Pause opens the pause menu.
Pause menuPause resumes the game (in co-op, pausing stops both windows and each player presses Pause to resume). Move up/down highlights an item, and Punch (Auto mode: Attack) chooses it.
Continue?Move up/down moves a dot between YES and NO, and Pause or Punch picks it.
Title, menus, character selectMove jumps a gold frame between the screen's buttons. Pause, Punch (Auto mode: Attack) or Jump picks the marked button, and D goes back. Screens without buttons, like the title, continue with Pause. The mouse works too.

Play

Your settings are saved automatically. For two players, in each window go to Mode Select → Double Dragon Mode → Matching Start.

Launcher

Using the Double Dragon app from your GitHub build? Everything here is built in there, with Play buttons, so you can skip this section.

  1. Put touchHLE.exe (your patched Windows build) and DoubleDragon.ipa in the same folder.
  2. Unzip the launcher into that folder. It has Play Double Dragon - 1 player.bat for playing alone and, when 2 players is selected above, Play Double Dragon - 2 players.bat for co-op.
  3. For two players, both windows open. In each window, go to Mode Select → Double Dragon Mode → Matching Start. They connect by themselves.
  4. Windows can also be resized by dragging a corner. With two players on one screen, a big window for player 1 and the original size for player 2 works well; Full screen covers the other window (use Alt+Tab to reach it).
  5. If you added a Double Dragon line to touchHLE_options.txt earlier, delete it, or both windows will pick up the same bindings.
